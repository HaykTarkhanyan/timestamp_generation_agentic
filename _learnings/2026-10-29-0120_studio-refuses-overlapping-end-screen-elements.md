# Studio refuses end-screen elements that overlap or sit too close

**Context:** 2026-10-28, Q43-Q47: an idea to move the elements onto the boxes of the lecturers' hand-drawn end cards
(Sevak, Papikian, Tserunyan; the cards start ~7-8 s before the end). A drag test was made and discarded.

**Found:** drags in the editor move an element exactly where it is dropped, but Studio will not save a layout where
elements overlap or come too close to each other. The drawn boxes did not match the template's layout, so the user
kept the standard template at 10 s and dropped the idea.

**Not measured:** the minimum gap Studio accepts. Find it first if element placement ever comes back.
