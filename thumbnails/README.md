# ML lecture thumbnails — design system & conventions

Generated by [`scripts/make_thumbnails_final.py`](../scripts/make_thumbnails_final.py).
Output: `thumbnails/ML0N.png`, each **1280×720** (`figsize=(12.8, 7.2)`, `dpi=100`)
— YouTube's recommended thumbnail size.

This file is the canonical record of the locked design and the per-lesson
conventions, so the next batch stays consistent without re-deriving it.

### Title sizing (auto-grow for short titles)

`title_size` in each lesson config is a baseline. At render time:

- **Single-line titles** (no `\n` — the "not text-heavy" cases) **auto-grow** to
  fill the width, capped at **74pt**, never shrinking below the configured size.
  The size is computed by *measuring* the rendered text with matplotlib's
  `get_window_extent` (exact for Adamathuz's real glyph widths), via
  `_fit_single_line_size()`. Short titles (e.g. ML06 `Մոդելի գնահատում`) hit the
  cap; longer single lines fill the width.
- **Multi-line titles** keep their configured size (they're height-constrained;
  auto-growing them would push into the illustration). If a short title still
  reads small as one line but is already width-maxed (e.g. ML04), **wrap it to
  two lines and raise `title_size`** — shorter lines unlock a bigger font. ML04
  is `"Գծային ռեգրեսիան\nզրոյից"` at 78.

Rule of thumb: not text-heavy → bigger title. One line auto-grows; if it's
already full width, wrap to two lines and bump the size manually.

## Palette (Armenian flag on white)

- orange `#F2A800` — accent bar, practical badge, highlights
- blue `#0033A0` — tag, scatter points, "positive" bars
- red `#D90012` — fit lines, descent arrows, "negative" bars
- charcoal `#0e0e0e` — title; grey `#5a6478` — residuals

When a chart has 3+ categorical colors, use this flag trio (project rule).

## Fonts (gotchas)

- **Adamathuz Bold** (`fonts/adamathuz/Adamathuz Bold.ttf`) — the title font.
  **Uppercase-Armenian only**: lowercase Armenian renders as uppercase, and it
  has **no Latin glyphs**. So titles and the badge must be pure Armenian; any
  Latin (`sklearn`, `EDA`, `log`) goes in the illustration panels, never the title.
- **Segoe Script** (Windows system font) — the `ML NN` tag. Latin/handwritten.
- **Sylfaen** (Windows system font) — mixed-case Armenian inside panels
  (panel titles, pipeline box labels). Use this whenever you need lowercase
  Armenian, since Adamathuz can't do it.
- The harmless render warning `Glyph 'l'/'p' missing from Adamathuz` comes from
  matplotlib probing the title font for the math-panel fallback — ignore it.

## Conventions

1. **Numbering.** Thumbnails map 1:1 to lesson number: `ML01`–`ML03` are the
   theory lessons; **`ML04` and `ML05` are the two practical sessions**
   (originally uploaded as `[04] Practical 01/02`). Practicals continue the
   count rather than reusing the theory number.
2. **`Գործնական` badge.** Practical (hands-on/coding) lessons get the orange
   `Գործնական` pill, top-right. Driven by `"practical": True` in the lesson
   config — theory lessons (`ML01`–`ML03`) must NOT have it. Text is Armenian
   in the title font (renders as `ԳՈՐԾՆԱԿԱՆ`).
3. **Illustration philosophy — hero vs concept-panels.** Two grammars, pick the
   one that fits and vary them across adjacent lessons so videos look distinct:
   - **Hero**: one bold chart spanning the band (e.g. `ML04`'s line-fit). Best
     when a single image instantly = the topic; reads well at small size.
   - **Concept-panels**: three side-by-side sub-panels, each with a short Sylfaen
     title (e.g. `ML05`'s log / correlation / coefficients). Best for
     multi-topic practicals; each panel is self-contained.
4. **Prefer faithful, real-data illustrations.** Redraw the course's own figures
   in the thumbnail palette (e.g. `ML04` mirrors `figures/grad_desc_alpha`'s
   contour + zig-zag descent), and drive charts from real lesson data
   (`ML05`'s histogram + correlations come from `House_Rent_Dataset.csv`).
   Bin heights / correlation values are baked into the script as constants so
   rendering needs no external data file.

## Running

```bash
# render everything
python scripts/make_thumbnails_final.py

# render only specific lessons (substring match on output filename)
python scripts/make_thumbnails_final.py ML04 ML05
```

The filter lets you regenerate one lesson without touching the others' PNGs.

## Adding a lesson / swapping an illustration

1. Write a `draw_*(fig, bbox)` function (single hero) or a `draw_*_panels`
   composite (carves `bbox` into sub-panels). `bbox = (x, y, w, h)` in figure
   coords; the band is wide (~3.8:1), so heroes should be wide-friendly.
2. Add a dict to `LESSONS`: `tag`, `title` (Armenian), `title_size`,
   `draw`, `out`, and `"practical": True` if it's a coding session.
3. To swap an existing lesson's art, just point its `draw` at a different
   function. Alternates already defined and ready to swap in:
   - ML 04: `draw_gradient_descent_panels` (contour panels),
     `draw_gradient_descent_panels_surface` (adds a 3D error surface)
   - ML 05: `draw_pipeline_panels` (vertical sklearn pipeline),
     `draw_pipeline_hero` (wide 4-stage flow)
