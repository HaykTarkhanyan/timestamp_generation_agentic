📌 Նկարագիր (Opus 4.8)
ML բաժնի երրորդ դասը նվիրված ա պրակտիկ տվյալների նախապատրաստմանը՝ երեք մեծ թեմա մեկ դասում։ Առաջինը՝ բացակայող տվյալներն են. ինչպիսի՞ տեսակներ կան (անմեղ, կառուցվածքային, վտանգավոր/կողմնապահ), ե՞րբ բռնել-շպրտել տողն ու սյունը (բութմատի օրենք՝ 70/90%), mean/median/mode/constant imputation, KNN-ով լրացում (խելացի, բայց հաշվարկային եքա բեռ + չափողականության անեծքը), missing indicator սյուն, և մոդելով բացակայողը գուշակելու հարցի քննարկում։ Հետո՝ duplicates ու outliers (box plot, z-score, isolation forest)։ Երկրորդ թեմա՝ կատեգորիկ կոդավորում. ordinal encoding (երբ կա հերթականություն), one-hot encoding (ամենից տարածվածը), one-hot-ի multicollinearity ու drop_first=True տրյուկը, label encoding, և բարձր cardinality-ի համար «other» bucket-ով կրճատում։ Հատուկ ուշադրություն ա դարձվում target encoding-ին՝ ամենահետաքրքիր, բայց ամենավտանգավոր մոտեցումը, որով հեշտ ա data leakage ստեղծել։ Հետո ամսաթիվ/ժամի համար feature extraction և sin/cos cyclical encoding-ի տրյուկը (որ ժամը 23-ը մոտիկ լինի 0-ին)։ Երրորդ թեմա՝ scaling. ինչու ա պետք (հեռավորության վրա հիմնված ալգորիթմներ, gradient descent), Min-max, Standard ու Robust scaler-ները, sklearn-ի fit/transform pattern-ը, scaling-ի դերը մոդելի մեկնաբանության համար, և թիրախի log ձևափոխությունը երկար պոչով բաշխումների համար (աշխատավարձ)։ Վերջում ընդգծվում ա, որ data leakage-ը գերագույն օրենք ա՝ ամեն ինչը հաշվարկում ենք միայն train տվյալների վրա, test-ը ուրիշ տեղ ենք «թաքցնում»։
