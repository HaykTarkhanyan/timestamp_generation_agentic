# non_essential

Scripts that are maintained and reusable, but not needed to run the timestamp /
publishing pipeline. Nothing in `scripts/` imports these.

| script | what it does | when you would re-run it |
| --- | --- | --- |
| `quantize_shrek.py` | Trims the white margins off `ml/09_clustering/img/shrek.webp`, downscales it, and runs the lesson-35 k-means colour quantization at k=4 and k=32 (seed 509), writing the three ML35 thumbnail panels into `thumbnails/assets/`. | Re-run if the source image changes, or to regenerate the ML35 panels at different k values. Prints the original unique-colour count, which is the caption on the first panel — update `draw_ml35_quantization` if it changes. |
| `split_figure_panels.py` | Splits one multi-panel course figure PDF into a separate PNG per sub-plot, so `_draw_image_row` can size, space and caption each panel itself. Finds the boundaries by scanning for all-white gutter columns instead of taking crop fractions by eye; `--crop-top` drops the sub-plot title band first, `--keep` picks which panels to write. | Whenever a thumbnail wants some of the panels out of a figure that holds a row of them (used for ML36's eigen-garments, ML37's mammoth, and ML38's Novembre 2008 panel a, where `--crop-bottom` drops the sub-panels below and a raised `--min-width-frac` discards the tiny "a" label). If it finds the wrong number of panels, adjust `--gutter-tol` (how many stray ink pixels a column may hold and still count as a gutter), `--white`, or `--min-width-frac`. Reads figure PDFs and already-raster borrowed PNGs alike; `--page` picks a page past the first, for borrowed slide decks like `lmu_src/*.pdf` (ML40 page 7, ML41 page 6). |
| `photo_scatter_ml39.py` | Renders the ML39 photo map: the lesson-39 practical's 92 demo photos drawn at their own projected positions instead of as coloured dots. Reads the coordinates and the base64 thumbnails straight out of the notebook's generated Plotly page (`out/demo_photos_map_{pca,umap}.html`), so nothing is recomputed and no umap-learn install is needed. `--figsize` stretches only the positions, never the images, which is how the projection is fitted to a 16:9 thumbnail band. | Re-run if the practical regenerates its maps, or to try `--map umap` / a different `--zoom`. |
| `lr_schedules_asset.py` | Redraws the ML44 learning-rate-schedule figure straight into `thumbnails/assets/`, with the dashed blue curve labelled just "linear decay". The course figure (`fig/lr_schedules.pdf`, from that chapter's `py_src/modern_components_figs.py`) calls it "linear decay (LMU)"; the user flagged that attribution as wrong, and redrawing here avoids regenerating the course figure out of step with the already-published slide deck. The curve maths is copied verbatim from `lr_schedule_figure`, so the shapes match what the lecture showed. | Re-run if the ML44 thumbnail needs rebuilding. If the course figure itself gets corrected, delete this and go back to `pdf_to_asset.py` on `fig/lr_schedules.pdf`. |
| `thumbnail_style_options.py` | Design exploration: renders the candidate thumbnail styles the user kept (bignumber, notebook, highlighter; six others were tried and dropped) on finished lessons, reusing each lesson's own draw function, plus `thumbnails/style_options/overview.png` with today's locked design as the first row. Production thumbnails are untouched. | Re-run to preview a style on other lessons (`... ML39 ML45`), or after tweaking a style. If one gets adopted, port it into `make_thumbnails_final.py` and move this to `archive/`. |
| `thumbnail_font_options.py` | Font comparison sheet for the kept styles: one row per candidate Latin title font (installed Windows/Office fonts, plus any `.ttf` in `fonts/candidates/`), three columns (bignumber·ML44, notebook·ML24, highlighter·ML46), written to `thumbnails/font_options/fonts_overview.png`. Loads fonts by file, never by name, and prints under each name any title character the font lacks. | Re-run after dropping new `.ttf` files into `fonts/candidates/`, or to compare fonts on other titles (edit `COLUMNS`). Archive together with `thumbnail_style_options.py` once a font is chosen. |
| `build_umath_plates.py` | Builds the text-free background plates for the umath thumbnail templates (`thumbnails/umath/templates/{ant,metric,linalg}_plate.png`) from the YouTube thumbnails in `thumbnails/umath/reference/`: flat fills for ANT and linear algebra; for Metric a merge of five references with the shared text inpainted and the red axis line redrawn. ~10 s. | Only to rebuild a plate (new references) or to add a series; `scripts/make_umath_thumbnails.py` just reads the PNGs. Details in `_knowledge/umath_thumbnails.md`. |
| `playlist_overview.py` | One standalone page for checking a whole playlist: each video's thumbnail, title, visibility, length, chapter count and description, from the live API, plus a signed-out check of every link in the descriptions (a Drive link that asks to sign in is not public; a Drive PDF named "05 ..." must sit in "Դաս 5"; YouTube links go through oEmbed). Saves `overview.json` first, builds `overview.html` from it. ~1 min for 14 videos. | Before making a course public, or after a batch of description pushes: `--channel umath --playlist <id> --out output/<name>`; `--html-only` rebuilds the page from the JSON. |
| `endscreen_template.js` + `make_endscreen_jobs.py` | **Not run yet (parked 2026-10-21).** One video's end screen in Studio through the Playwright MCP: template "1 video, 1 playlist, 1 subscribe", every element in the last 10 s, the video element the next lesson (found by search, card title must start "Դաս N \|") or "Best for viewer"; verifies, then saves. The generator writes one `.playwright-mcp/endscreen_NN_<lesson>_<id>.js` per Arnak video from `output/arnak_overview/overview.json` (12 -> 13, 2025 -> 13, 13 -> Best for viewer). The steps were done by hand on Arnak lesson 1 (saved). | To finish Arnak 2-13 + 2025: run the generator, then each file with `browser_run_code_unsafe(filename=...)`, one at a time, with the Playwright window uncovered. See DEFERRED_TODO. |
| `fetch_papikian_site.py` | Snapshots Mihran Papikian's Google Site into `_knowledge/papikian_site/`: the text of all six pages, every link with its context (`manifest.json`: label, kind, file, size, SHA-256) and the 104 Drive PDFs (both courses' notes, homework and exams; his research papers). Recordings are listed, not downloaded. `--plan` only parses (~5 s); `--download` fetches (~5 min, ~400 MB), and fails loudly on anything that is not a PDF. | The PDFs are git-ignored, so on a fresh clone run `--download` to get them back; also to refresh the snapshot if he updates the site (e.g. the Galois course). |
| `snap_chapters_to_captions.py` | After a Studio edit has been processed and the new captions fetched into `<folder>/edited/`: moves each chapter of `edited_predicted/timestamps.txt` (the chapters remapped onto the final cut list) onto the first word of its topic, using the new captions' per-word timing; a match more than 1 s later is not taken (usually a garbled first word). Writes `edited/timestamps.txt` and logs every move. | After each edited lecture, before reviewing and pushing its chapters. Papikian 16-23 (2026-10-22): moves of 1-3 s on 46 of 181 chapters. |
| `glossary_scan_channels.py` | Runs the glossary cross-check (`.claude/skills/youtube-timestamps/scripts/glossary_check.py`) over the title and description of every upload on both channels and the umath channel's Sevak chapter comments; saves every finding to `output/glossary_scan/scan.json`. Read-only, ~100 s. First run 2026-10-22: 0 DENY after the fixes, 85 NEAR, 385 ENG (mostly the ML course's deliberate English). | After adding a term to `glossary_denylist.csv`, to find where else it was published; or before calling a course "all good". |
| `range_server.py` | Static file server with HTTP Range support. Playwright blocks `file://`, and Python's `http.server` ignores Range, so without this a browser test of `edit_review/studio.html` can't seek in the 200 MB lecture WAV. | Only to test the edit-points review page in Playwright: serve the `output/<dir>` folder and open `/edit_review/studio.html`. |
